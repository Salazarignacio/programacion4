Guía de Carga de Datos en Postman

Proyecto: Gestor de Pedidos (API REST - Spring Boot)

Base de Datos: H2 en memoria (los datos se reinician al apagar/reiniciar el servidor).

Instrucciones de Uso en Postman:
1. Para los métodos POST y PUT, seleccionar el formato Body -> raw -> JSON.
2. Seguir el orden de pasos indicado a continuación (primero Categorías y Usuarios, luego Productos, luego Pedidos y Detalles) para asegurar la integridad de IDs.

PASO 6: Endpoints de Verificación Solicitados por la Consigna

  • GET http://localhost:8080/usuario/mail/ignacio@gmail.com (Buscar Usuario por Mail)
  • GET http://localhost:8080/usuario/1 (Buscar Usuario por ID)
  • PUT http://localhost:8080/categoria/1 (Actualizar Categoría)
  • GET http://localhost:8080/swagger-ui/index.html (Swagger UI interactivo)
